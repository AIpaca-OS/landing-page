# Rumbo — Landing Page

Landing Page del producto **Rumbo**, desarrollado para el curso **1ASI0729 Desarrollo de Aplicaciones Open Source** (NRC 7760, ciclo 2026-20).

## Alcance AV1

Para AV1 debe existir una **primera versión implementada y desplegada** del Landing Page. Este repositorio se utilizará únicamente para ese producto.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Internationalization con `en_US` y `es_419`
- Accessibility con atributos ARIA cuando corresponda

El idioma por defecto de la experiencia del producto será inglés.

## Contenido esperado

La primera versión deberá comunicar de forma clara:

- propuesta de valor de Rumbo;
- problema que aborda;
- beneficios para padres/tutores;
- beneficios para conductores de movilidad escolar;
- principales características del producto;
- llamados a la acción;
- información de contacto;
- términos y condiciones accesibles desde el footer.

## Control de versiones

Se utilizará GitFlow con `main`, `develop` y ramas `feature/...` creadas únicamente cuando exista trabajo real que implementar. Los commits seguirán Conventional Commits y las versiones publicadas seguirán Semantic Versioning.
